# gacee-docs

Static documents published for the Global Association of Cultural and Educational Exchange (GACEE).

- `hanqiao-plan.html` — HanQiao Delivery Plan (中英双语, v3.0)
- `brand-guidelines.html` — GACEE brand manual
- `index.html` — document index

Deployed with Vercel to docs.gacee.org. Documents are marked `noindex`; links are unlisted but reachable by anyone holding the URL.
