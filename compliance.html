01现状与目标

先厘清协会当前的法律状态，据此把"现在可做/须做"和"注册为非营利后再启用"的保护分层。

现状 已具法人

协会已完成 ACRA 法人登记，具独立法人与有限责任（[登记形态，如担保有限公司 CLG]），可以法人身份对外签约、开立账户、接受资助；[慈善 / IPC 税务优惠地位待申请]。涉及资金、政府对接、未成年人数据的刚性风险须持续严防（见下）。

目标

① 以最小法务风险完成三方协议签署与四国试点；② 建立可复制的合同与合规框架，成为协会与所有项目 / 资源方合作的模版；③ 以法人身份规范治理，为协会申请新加坡慈善 / IPC 地位铺好财务与治理底座。

三条刚性风险（与慈善 / IPC 地位无关，须持续严防）：（1）反贿赂——乙方涉政府对接，一旦发生不当付款，全体三方及个人可能触犯新加坡《防止贪污法》并具域外效力；（2）未成年人数据与儿童保护——服务对象多为学生，须家长同意、数据最小化、背景审查；（3）资金与账户——收款账户与资金流须清晰、可追溯，避免个人代收与混同。

五道防火墙

防火墙隔离什么怎么落地
① 法律实体个人 / 机构责任乙方（Ray/当地方）以公司主体签约；协会已具 ACRA 法人；各方独立主体、独立账户。
② 责任连带 / 商业赔偿协议写明各自领域负责、责任上限、互相赔偿；协会责任限于自身故意/重大过失。
③ 资金资金混同 / 代收分账、协会款项进协会名义账户；学生费用由 JE AI/当地主体收取；禁止个人代收。
④ 知识产权与品牌IP 流失 / 品牌滥用AI 中文学习平台的技术成果（代码、算法、JE 引擎、智能体架构、TIDAR-KAG、界面设计等）归 JE AI，仅以非转让许可授权各方使用；山海同文品牌归协会，受质控许可、可撤销。
⑤ 数据与合规数据/贿赂/制裁PDPA + 未成年人 + 儿童保护 + 反贿赂 + 制裁/出口管制，作为协议优先条款。

03合规防火墙清单

签约与运营中可直接执行的"做/不做"清单，降低法务风险。

应做 Do

  • 所有对外合作先签框架协议，具体项目签专项协议。
  • 乙方以公司主体签约；协会尽快登记 CLG。
  • 资金进协会名义账户，凭证留痕、可审计（见 §04）。
  • 与公职人员往来全程留痕、遵守礼品与款待规则。
  • 学生数据取得家长同意；人员做背景审查。
  • 用印/签署经授权代表、按分级授权（见 hub 平台）。

不做 Don't

  • 不以个人名义代收项目/学生款项。
  • 不作出超出协议范围的对外承诺或以三方名义担保。
  • 不向政府官员提供任何不当好处 / 疏通费。
  • 不把学生/客户数据用于项目外用途或未经同意跨境。
  • 不签无适用法/无争议解决条款的合同（须新加坡法 + SIAC）。
  • 不在无 DPA / 儿童保护附件的情况下上线试点。

04顶级 NGO 财务会计制度

对标新加坡《慈善法》《慈善与 IPC 治理准则》与国际 NGO 最佳实践；协会虽已完成 ACRA 法人登记，慈善 / IPC 资格尚在申请，建议现在就按此建账，为申请与审计铺路。

治理与内控

  • 三权分立：经办 / 审批 / 出纳分离；任何付款双人授权；大额按分级授权（≤5k 部门 / ≤20k 财务 / ≤100k 秘书长 / >100k 理事会——与 hub 平台一致）。
  • 理事会 + 财务委员会监督重大事项与预算；重大决策集体决议、全程留痕可查、定期向理事会报告。
  • 预算年度编制、按季复核；采购到付款（P2P）询价→合同→验收→请款→付款全程留痕（见 hub 平台）。

基金会计与科目

要点做法
限定 / 非限定资金捐赠按用途分「限定用途」与「非限定」分别记账，专款专用，不得挪用。
会计科目表收入（会费/捐赠/资助/项目/服务）· 支出（项目/教学/行政/筹款）· 资产/负债/基金结余，按项目与成本中心核算。
收付实现 vs 权责发生建议权责发生制，编制收支表、资产负债表、现金流量表、基金变动表。
储备金政策设定运营储备（如 6–12 个月支出），书面披露储备水平与理由。

银行、税务与报告

  • 账户分离：协会名义账户；收款、支付、储备分设；与 JE AI / Ray 资金零混同。
  • 税务：慈善可享税务豁免；IPC 可开具可抵税捐赠收据；关注 GST 门槛与跨境服务税务。
  • 报告与审计：年度财务报表 + 外部审计（达规模）；向 ACRA / 慈善总监（COC）年报；遵守《治理准则》披露理事、重大事项与高管薪酬。
  • 捐赠透明：公开透明台账（呼应 hub 平台公益模块），大额捐赠与用途可追溯。
与平台打通。hub.gacee.org 的合作·采购·结算与资产管理模块已按此制度设计（分级授权、AP 账龄、成本中心、审计留痕、固定资产折旧、无形资产台账），可直接作为协会财务系统的执行层。
