数据处理附录 DPA
Data Processing Addendum · 含未成年人数据

《三方战略合作框架协议》/《项目专项协议》附件 · 适用法律：新加坡 PDPA + 属地法 · 版本 1.0（草案）

草案 — 仅供审阅。 本附录规定平台处理个人数据（含未成年学员数据）的规则，作为框架协议 / PSA 的组成部分并优先适用于数据条款。方括号 [ ] 为待填项。

当事方与角色

数据控制者（Controller）：[决定处理目的与方式的一方——通常为项目学校 / 协会]

数据处理者（Processor）：Juris&Edu AI Technology Pte. Ltd.（"JE AI"），依控制者指示处理数据的平台运营方。

角色按项目据实认定；如协会仅提供教研与背书、不决定处理目的，则控制者为学校，协会为另一独立控制者或不涉。

第一条 定义

  1. 个人数据：可识别自然人的任何信息，含学员姓名、联系方式、作业与作答、语音与影像、学习行为与掌握度数据等。
  2. 未成年人：依属地法未达成年年龄的学员（[各国年龄以属地法为准]）。
  3. 处理：对个人数据的收集、记录、存储、使用、传输、删除等任何操作。
  4. 子处理者：受处理者委托处理个人数据的第三方（如模型网关、语音合成、云与 CDN 服务商）。

第二条 处理范围与指示

  1. 目的限定：仅为教学交付与学情分析之目的处理数据；不得用于项目外用途或未经同意的营销。
  2. 按指示处理：处理者仅按控制者书面指示处理；本附录及 PSA 即为初始书面指示。
  3. 数据最小化：只收集达成目的所必需的数据；能匿名 / 去标识的即去标识（对接平台 PII 去标识）。
  4. 人员保密：接触数据的人员负保密义务并经培训。

第三条 未成年人数据（重点）

服务对象多为未成年学员，此条为刚性要求。
  1. 监护人同意：处理未成年人数据前，须取得家长 / 监护人可核验的同意；同意记录留痕、可撤回。
  2. 最小化与用途：仅用于教学；不作画像式营销、不向第三方出售。
  3. 语音 / 影像：老师音色复刻与课堂音视频须单独授权、限本班教学用途、可删除。
  4. 可删除 / 可导出：监护人可要求导出或删除其子女数据（法定留存除外）。

第四条 安全措施

  1. 传输与存储加密；最小权限访问控制与操作留痕；定期安全评估。
  2. 数据驻留：默认 [新加坡] 驻留；PII 去标识后再进入模型链路。
  3. 备份与恢复、密钥管理、终端与账户安全；弱网 / 离线场景下本地数据同样受保护。

第五条 子处理者

  1. 处理者可委托子处理者，但须：事先书面告知控制者并取得概括或逐一同意；与子处理者签订不低于本附录的数据保护义务（义务传导）。
  2. 现有子处理者清单（示例）：[模型网关 / 语音合成 / 云与 CDN 服务商]；变更提前通知，控制者可合理反对。
  3. 处理者对子处理者的行为向控制者负责。

第六条 跨境传输

  1. 如需将数据传出属地，须具合法路径（充分性认定、标准合同条款 / 约束性规则、或经同意等），并采取保障措施。
  2. 按属地法（[越 PDPD / 印尼 UU PDP / 马 PDPA / 新 PDPA]）履行跨境要求；出境记录留档。

第七条 数据主体权利

  1. 处理者协助控制者应对数据主体（或其监护人）的查阅、更正、删除、撤回同意等请求，在 [合理期限] 内响应。
  2. 不得妨碍数据主体行使法定权利。

第八条 数据泄露通知

  1. 发生或疑似发生个人数据泄露，处理者不迟于知悉后 [72] 小时通知控制者，说明性质、范围、影响与已采取 / 拟采取的措施。
  2. 依属地法要求配合向监管机构与受影响个人的通报。

第九条 审计与记录

  1. 处理者保存处理活动记录，并在合理通知下配合控制者审计 / 核查（含第三方审计报告替代实地审计）。
  2. 记录留存期限与格式按属地法与《合规 · 法务 · 财务建议书》§04。

第十条 期限与终止后处理

  1. 本附录随框架协议 / PSA 存续。
  2. 终止后，处理者按控制者选择返还或删除全部个人数据及副本（法定留存除外），并出具确认。

第十一条 适用法律与争议

本附录适用新加坡法律并结合各试点国属地数据法；争议提交 SIAC 在新加坡仲裁。属地法有强制规定的，从其规定。
