01定位与边界

GACEE 数字体系由三套相互独立的系统组成。本规划只覆盖「协会平台」；它同时是官网内容的源头。

带登录/权限的运营中枢 + 官网内容源头。新建

learn.gacee.org

山海同文 · AI 中文

AI 中文学习产品，独立项目。不在本期·不混入

硬边界。 协会平台与山海同文绝不混到一起：各自独立仓库、后端、数据、排期。平台代码/数据/运行时彻底独立：AI/Agent 用 JE 代码单独部署一套（独立实例、独立数据，不共用 jurisedu 在线服务）。两系统仅经约定接口衔接：山海同文的结业证书由平台统一签发/验真、阶段 2 SSO；平台不承载其教学功能。出版/图书纳入本期。

02系统架构

已拍板：新建独立平台 app + 独立后端，代码/数据/运行时与 jurisedu 解耦；AI/Agent 用 JE 代码单独部署一套（独立实例）；官网作为 headless 前端实时拉取平台内容。

技术栈

  • 前端：Next.js（App Router）+ 多语言（zh/en，可加 fr）

  • 地图：研学地图组件（服务商见 §12 待定）
  • 收款：Stripe（协会名下账户）

部署与产权

  • 部署可复用 JE 新加坡 k8s + Cloudflare（仅基础设施）

认证状态决定开放程度

  • 非认证：可浏览、报名、捐赠、投稿（经审）；发布可对接资源、查看联系方式受限，须先认证。
  • 认证：资源可公开对接、联系方式按设置可见、一般类资源免审核、更高可见性、带「协会认证」徽章。

运营按职能分权

  • 内容复核 · 对接审核 · 认证审核
  • 财务（缴费 / 捐赠）
  • 资源管控（可见性 / 下架 / 申诉）

赛事/交流扩展角色：评审专家（评审阅卷，作文老师主导）、指导老师/领队、学生/家长、合作机构（赛事方）——各自权限并入平台 RBAC。

后续补充（规划位）。 ① 会员证书与认证：会员/机构认证徽章、协会统一发证与验真，与 §10 证书中枢打通；② 会员权益体系：分层权益、资源优先对接、活动/研学折扣、专属内容与线下礼遇等——将在后续版本细化。

05内容投稿与发布

官网 gacee.org 的所有信息与文章投稿都来自本平台。内容经「投稿 → JE Agent 初审 → 人工复核 → 发布」后，官网实时拉取。已定

投稿文章 / 图片 / 视频
→
JE Agent 初审合规筛查·润色纠错·事实标注·分类摘要
→
人工复核运营·内容复核职能
→
发布官网实时拉取 API

谁能投稿

  • 认证会员 · 所有注册会员 · 合作机构 · 运营自采
  • 非认证会员投稿须经审核；认证会员流程更快

JE Agent 编辑初审（四项）

  • 合规 / 敏感内容筛查（标风险供人工复核）
  • 文字润色与纠错（不改原意）
  • 事实核查 · 标注存疑（不自作主张）
  • 自动分类 / 打标 / 摘要 / 封面建议

内容工作流状态

  • draft 草稿 / 投稿
  • ai_reviewed JE Agent 初审完成（含评分与标注）
  • in_review 待人工复核
  • published 已发布（官网可见）
  • rejected / returned 退回并附理由

官网对接

官网实时拉取 API（headless）：发布后官网即时可见，官网无独立内容库。

JE Agent 只做初审、不终审。 输出为建议与风险标注，人工复核后才发布；敏感内容一律人工把关。

08资源信息管控

作为贯穿性设计，而非单独功能。

  • RBAC：7 类身份 + 运营按职能分权（见 §03）。
  • 可见性分级：公开 / 会员 / 仅认证 / 定向机构 / 私密；非认证看不到联系方式。
  • 分资源类型审核：资金、名额、专家等敏感资源对接须审核；一般资源双方同意即可。
  • 双方同意机制：对接是「申请 → 同意」两步，防裸抓。
  • 内容三道关：投稿 → JE Agent 初审 → 人工复核，敏感内容一律人工把关。
  • 审计留痕：查看/对接/下载/发布可追溯。
涉资金红线。 缴费与捐赠收款账户须在协会名下；费率、价格、支付通道按区域实测后确定，规划阶段不写死数字。

10证书发证与验证

协会证书的发放与验真都在本平台——它是协会统一发证与验真中枢；山海同文的结业证书也经此平台发出（山海同文作为消费方经接口发证）。

发证

  • 按项目/活动的证书模板批量或单个签发
  • 每证 唯一编号 + 二维码，绑定持证人与来源
  • PDF/图片导出；可作废/重发，全程留痕
  • 签发权限受控（运营·证书职能）；对外提供发证接口供山海同文等调用

验证

  • 公开验真页（verify.gacee.org 或 /verify/[id]）
  • 扫码 / 输编号 → 显示真伪、持证人、来源、状态
  • 防伪防篡改；作废证书显示已失效
边界。 平台只发协会自己的证书（含山海同文结业证书）；HSK/YCT 等官方认证走官方考点，平台不冒充官方发证。山海同文经接口发证=干净的共享服务，不把教学功能混入平台。
