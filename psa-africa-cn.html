第一条 定义与解释

平台 / Platform
指甲方自主研发并拥有的 AI 中文学习平台,含其 JE 引擎、JE 混合编排智能体阵列、TIDAR-KAG 低幻觉检索、模型编排、算法、源代码、架构、数据模型及全部技术成果,以及甲方不时对其的更新与改进。
甲方既有知识产权 / Background IP
指本 PSA 生效前已存在或由甲方独立开发的知识产权,包括平台。
项目定制成果 / Foreground IP
指专为本项目、依乙/丙方书面需求另行定制开发、且不属于平台通用能力的成果(范围应尽量收窄,见第五条)。
项目内容 / Project Content
指协会及其授权方提供或制作的中文课程、教研材料、教学方法、HSK 学习体系、题库与品牌资产。
项目数据 / Project Data
指本项目运营中产生的学习者档案、出勤、作业、测评、学习行为、进度、ILAP 与报告等数据。
技术规格 / Specifications
指附件一(《技术规格附件》)所载之功能与技术要求。

解释规则:标题仅为方便;"包括"指"包括但不限于";单复数互通;提及法律指经不时修订之该法律;本 PSA 与框架协议冲突时依第二条处理。

第二条 文件效力与顺位

本 PSA 为框架协议附件一,与之共同构成完整协议。发生冲突时,效力顺位为:

  1. 就该项目商业条款(费用、出资、分成、规模):本 PSA 正文优先于框架协议;
  2. 就知识产权、品牌、数据保护、合规、争议解决等原则性条款:框架协议优先;
  3. 本 PSA 正文优先于其附件;附件之间以列明顺序为准。

第三条 项目范围与分期

  1. 范围:在 [尼日利亚 / 城市 / 学校] 面向 [年级 / HSK 起点] 学习者,以"真人教师 + 数字化学习 + AI 辅导 + 持续评估 + 个性化干预"模式提供中文学习服务。
  2. 分期交付:本项目分阶段实施。第一阶段(MVP)范围以附件一及附件四(《验收与里程碑》)所列为准,并非附件一全部功能一次性交付至生产级;后续能力按变更管理(第十七条)迭代。
  3. 教育目标:项目设计目标为辅助学习者在约 [2] 年内达 HSK 四级;该目标不构成对任何学习者考试成绩或官方 HSK 认证的保证(第十三条)。
  4. 不在范围:官方 HSK 报名与发证、留学招生托管,及本 PSA 未列明之服务。

第五条 平台许可与知识产权

核心条款。本条确立:平台是甲方既有 IP、以许可提供;非"项目定制成果",不发生向乙/丙方之转让或共有。
  1. 甲方既有 IP。平台及其一切组成部分(引擎、智能体编排、TIDAR-KAG、算法、源代码、架构、数据模型、AI 模型等)为甲方既有知识产权,归甲方所有;本 PSA 不构成任何转让或共有。第三十条及第四十七条式的"定制成果"表述不适用于平台通用能力。
  2. 许可授予。甲方就本项目授予乙、丙方及当地对接方一项非独占、不可转让、不可再许可、可撤销的许可,仅限在本项目范围与授权地域内使用与推广平台。未经甲方书面同意,任何方不得复制、修改、反向工程、出售、再许可或以其他方式处分平台或甲方 IP。
  3. 项目内容 / 项目数据。项目内容归丙方(协会)或其授权方;项目数据归丙方或客户(数据权利主体),并按附件五(DPA)处理。甲方仅为处理者/受托方,不因提供服务而取得其所有权。
  4. 项目定制成果。如有专为本项目、超出平台通用能力、依书面需求另行定制之成果,其归属与许可在附件二逐项约定;缺省情况下,凡属平台底层能力之延伸者归甲方并纳入平台。
  5. 反馈许可。各方就平台提出的反馈与建议,甲方可无偿、永久用于改进平台。
  6. 品牌。"山海同文"品牌归协会,按附件《品牌许可》使用,受质控、可撤销;英文须用全称,不得裸用 "SHANHAI"。

第六条 技术规格与验收

  1. 平台第一阶段应实质符合附件一(《技术规格附件》)就 MVP 所载之要求。附件一中标注"原则上 / 在技术条件允许下 / 以 PoC 结论为准"者,为设计目标而非硬性保证。
  2. 验收。双方应于项目启动阶段共同书面确定验收标准与用例(UAT),并与 MVP 范围对齐、切合尼日利亚弱网/断电/低配实况(附件四)。
  3. 甲方按附件四完成测试(功能、集成、安全、性能、低带宽、离线、断网/断电恢复、低配安卓、AI、UAT)后交付验收;缺陷分级修复。

第七条 服务水平(SLA)

  1. 生产环境月度可用率目标 [99.5%](不含计划维护)。响应/修复时限、RTO/RPO 见附件三。
  2. 责任边界。SLA 仅就平台自身故障负责;当地互联网中断、电力中断、第三方会议平台/网络/CDN 故障、不可抗力不计入 SLA 违约。
  3. SLA 档位与附件二商业条款(价格)相匹配。

第八条 商业条款、出资与结算

待谈重点。规格书未涉商业条款;本项目的开发出资、许可/服务费、分成为成败关键,须在附件二明确,不得臆造。
  1. 出资。本项目平台适配与交付的开发出资安排 [由乙方 / 出资方承担 / 各方比例],见附件二。
  2. 费用。许可/服务计费方式 [按席位·月 / 按班 / 按校打包 / 订阅];单价与币种见附件二。
  3. 收款与零混同。学员/项目费用由 [甲方 JE AI / 当地商业主体] 收取,禁止任何个人代收;凡属协会款项一律入协会名义账户,与商业资金零混同,协会不因商业服务分配盈余。
  4. 结算。每 [月 / 季] 对账结算,附凭证与 AI 使用量/成本报告(附件三);争议部分暂缓、其余照付。

第九条 数据保护与儿童保护

  1. 本项目涉及未成年人数据。处理前须取得家长/监护人可核验同意;按附件五(DPA)及属地法(尼日利亚 NDPA 2023 / NDPR)与新加坡 PDPA 处理。
  2. 各方遵守《儿童保护政策》(附件六);接触学习者的人员经背景审查与培训;AI 输出设未成年人安全护栏。
  3. 数据最小化;跨境传输须具合法路径与保障措施;泄露按 DPA 约定时限通知。

第十条 业务连续性与数据可携

核心条款(替代源码托管)。客户所需的是服务连续性与数据/内容掌控,而非持有甲方源代码。
  1. 不托管核心源码。甲方无须就平台核心源代码设立第三方托管(escrow)。
  2. 数据与内容可携。甲方应随时/于终止时,以通用、结构化格式向数据权利主体提供项目数据、项目内容、系统配置之导出,并提供合理迁移协助;不得以技术手段阻碍。
  3. 服务连续性。甲方维持数据备份与灾备(附件三);如甲方停业、无法继续服务或长期严重违约且经通知未纠正,甲方应给予合理过渡期并协助数据/内容/配置迁移,以保障项目继续运营。
  4. 可选加强(如客户坚持)。可就项目数据 + 部署配置 + 文档(不含平台核心源码)设立托管或"连续性运营方"安排,条件另议。

第十一条 AI 治理与模型使用

  1. 人工监督。AI 负责分析、建议与辅助,授权教师/管理员保留最终教学判断;重要 AI 判断不得在无人工复核机制下永久锁定;教师可修改/覆盖/纠正/举报 AI 结果。
  2. 数据训练限制。未经数据权利主体书面授权,甲方不得将学习者/儿童数据、对话记录、项目内容用于训练第三方通用 AI 模型;为提供与改进本服务而在服务内进行的、去标识化处理不受此限(按 DPA)。
  3. 模型披露。甲方向丙方合理披露所用第三方模型、数据处理地及是否用于训练;但不披露甲方专有编排、提示工程、权重等核心 know-how。更换核心模型如重大影响成本/安全/效果,应提前通知。
  4. 成本控制。平台采模型路由/小模型优先/缓存/Token 优化;甲方按月提供 AI 使用量与成本报告。

第十二条 保密

各方对因本项目获知的对方非公开信息(含平台技术信息、商业条款、学习者信息)负保密义务,仅为履约目的使用,存续至信息公开或依法披露;本条于终止后存续 [3-5] 年,商业秘密无限期。

第十三条 陈述、保证与免责

  1. 各方保证有权签署并履行本 PSA。
  2. 甲方保证平台服务将以合理技能与谨慎提供,实质符合附件一 MVP 要求。
  3. 免责。在适用法允许的最大范围内,除本 PSA 明列者外,甲方不作任何明示或默示保证(含适销性、特定用途适用性);不保证任何学习者的考试成绩或官方 HSK 认证结果;不保证无中断或无错误。

第十四条 责任限制

  1. 在适用法允许的最大范围内,任何一方均不就间接、附带、后果性损失、利润/商誉/数据损失担责。
  2. 各方在本 PSA 项下的累计责任上限为 [违约方在前 12 个月依本 PSA 实收/应付金额 / 约定固定上限]。
  3. 上限例外(不受第 1、2 款限制):保密违反、数据保护/儿童保护违反、知识产权侵权、故意不当行为、依法不可限制之责任。

第十五条 赔偿

  1. 甲方就平台本身侵犯第三方知识产权的主张,在本 PSA 责任框架内向他方作出赔偿(客户按约使用、及时通知、由甲方主导抗辩为条件);甲方可修改/替换/取得授权或终止相关部分。
  2. 各方就其违反数据保护/儿童保护/保密或其重大过失给对方造成的第三方索赔,相互赔偿。

第十六条 期限、暂停与终止

  1. 本 PSA 自各方签署起生效,至第一阶段届满/续期之日止。
  2. 一方重大违约且经 [30] 日书面通知未纠正,守约方可终止;一方破产/停业,他方可即时终止。
  3. 终止后果:许可即时停止;数据/内容/配置按第十条移交;款项按已履行服务结清;第 5、9、10、12、14、15 条及依其性质应存续者继续有效。

第十七条 变更管理

任何重大功能/范围变更须经书面《变更请求(Change Request)》,载明内容、原因、对系统/时间/费用/数据安全/AI 之影响及双方审批人;未经批准的变更不产生义务;新增功能相应调整费用与工期。

第十八条 一般条款

  1. 转让/分包。未经他方书面同意不得转让本 PSA;甲方可分包但对分包方负责。
  2. 不可抗力。因不可抗力(含当地大规模断电/断网、天灾、战乱、政府行为)不能履行的,不构成违约,受影响方应通知并尽力减损。
  3. 通知。通知以书面并送达各方 [地址/邮箱] 为准。
  4. 完整协议 / 变更 / 弃权 / 可分割性。本 PSA 连同框架协议及附件构成完整协议;变更须书面;弃权不构成后续弃权;某条无效不影响其余。
  5. 无合伙 / 无代理。各方为独立缔约方,本 PSA 不构成合伙、合资或代理关系。
  6. 第三方权利。除本 PSA 明确赋予者外,《合同(第三方权利)法》(Contracts (Rights of Third Parties) Act 2001)不适用,非缔约方不得依本 PSA 主张权利。
  7. 副本。本 PSA 可分份签署,含电子签署,合为一份。

第十九条 适用法律与争议解决

本 PSA 受新加坡法律管辖并结合尼日利亚属地法解释;争议提交新加坡国际仲裁中心(SIAC)按其届时有效规则在新加坡仲裁,仲裁地新加坡,仲裁员 [一 / 三] 名,语言 [中文 / 英文]。本条独立生效,不因本 PSA 终止而失效。
