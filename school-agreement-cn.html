第一条 定义与"两阶段 + 转正"结构

  1. 两阶段：本协议分"第一阶段 · 试点期"（低承诺、易退出）与"第二阶段 · 正式期"（正式使用与收费）。
  2. 转正：试点结束后，经《采购确认单》（附件 A）由学校签署激活，即进入正式期，无需另订新约、无需重新谈判。
  3. 商业条款前置锁定：正式期的价格、席位、周期等已在签署本协议时于附件 A 预先约定并锁价；转正当期不改价（除双方另行书面同意）。
  4. 分阶段约束力：试点期除第六条（数据与儿童保护）、第七条（品牌与知识产权）、第八条（保密）外，原则上不具法律约束力；正式期一经激活，全面具约束力（详见第十条）。

第二条 第一阶段 · 试点期

  1. 范围与规模：学员 [20–40] 人；周期 [6] 周；每周 [1 次直播 + 1 节录播 + 每日练习]；起止 [ ]。
  2. 交付：录播 + 直播 + 离线练习 + 伴学 / 复习智能体 + 学习报告 + 结业证明（协会签发、可验真）。
  3. 试点费用：[全部免费 / 象征性]；第三方直接成本承担见附件 A（及内部《PSA》）。
  4. 低承诺与退出：试点期任一方可提前 [ 天 ] 书面通知退出，除已实际发生成本外不承担责任；试点不构成正式采购承诺。
  5. 成功标准：按附件 B 逐条评估，作为双方判断是否转正的客观依据。

第三条 转正机制（采购确认单）

本条为本协议的商业核心。把"第二次成交"从一轮重新谈判压缩为一张一页纸确认单。
  1. 成效报告：试点结束前 [ 天 ]，项目方对照附件 B 提供试点成效报告。
  2. 转正方式（主动签署 opt-in）：学校如决定转正，由授权代表签署《采购确认单》（附件 A）即激活正式期；确认单一经双方签署，即为本协议不可分割的组成部分。
  3. 价格锁定：正式期商业条款以附件 A 预先约定为准，转正当期不重新谈判、不涨价（锁价有效期至 [ ]）。
  4. 不转正之后果：学校未在 [ 期限 ] 内签署确认单的，试点友好结束，双方无进一步义务（第六 / 七 / 八条义务除外）；不适用任何自动续约或自动转付费。
  5. [备选条款 · 默认不启用] 静默续转：仅在双方明确书面同意且属地法允许时，方可约定"到期未反对即自动转入正式期"。因本协议涉及未成年人服务与（政府）学校采购，默认不采用此方式，以维护信任与治理合规。

第四条 第二阶段 · 正式期（商业条款）

  1. 计费模型：[按席位 / 月 · 按班 · 按校打包]；单价见附件 A。
  2. 周期与续约：正式期 [学期 / 学年]；到期续约采 主动续签确认单 方式，同样不默认自动续费。
  3. 服务水平：平台可用性目标 [%]；工单响应 [时长]；弱网降级（音频优先 / 离线）为约定能力。
  4. 支持与培训：教师培训 [ 场 ]；技术支持渠道 [ ]；本地助教协作。
  5. 规模调整：席位增减按附件 A 单价据实调整，月度对账，不溯及既往。

第五条 收款与结算

  1. 收款主体：正式期服务费由 [收款主体：JE AI / 当地商业主体] 收取；禁止任何个人代收。
  2. 协会款项零混同：凡属协会的资助、捐赠或应得款项，一律进协会名义账户，与商业资金零混同；协会不因商业服务分配盈余（见《合规 · 法务 · 财务建议书》）。
  3. 结算：每 [月 / 季] 对账结算，附凭证；争议部分暂缓、其余照付。
  4. 内部分工与学校无涉：项目方内部（协会 / JE AI / 资源方）的交付分工与分账，依《框架协议》与内部《PSA》处理，学校非该等安排之当事方。

第六条 数据与儿童保护（两阶段均具约束力）

涉及未成年学员，本条为刚性、贯穿试点与正式两阶段的约束条款。
  1. 处理学员数据前取得家长 / 监护人可核验同意；按《数据处理附录（DPA）》与属地数据法 [越 PDPD / 印尼 UU PDP / 马 PDPA / 新 PDPA] 处理。
  2. 遵守《儿童保护政策》；接触学员的人员经背景审查与培训。
  3. 数据最小化；跨境传输须有合法路径。

第七条 品牌与知识产权（两阶段均具约束力）

  1. AI 中文学习平台的技术成果（代码、算法、JE 引擎、智能体架构、TIDAR-KAG、界面设计等）之知识产权归 JE AI，按非转让许可供本合作使用。
  2. "山海同文"品牌归协会，学校使用须遵守《品牌许可协议》与《品牌手册》；英文须用全称 "SHANHAI TONGWEN"，不得裸用 "SHANHAI"。
  3. 学校不得将品牌或平台用于本合作范围外用途。

第八条 保密（两阶段均具约束力）

双方对合作中获知的对方非公开信息、学员信息负保密义务，存续至信息公开或依法披露。

第九条 期限、退出与终止

  1. 本协议自双方签署之日起生效；试点期与正式期期限分别见第二条与附件 A。
  2. 试点期退出见第二条第 4 项；正式期一方重大违约且经 [ 天 ] 未纠正，守约方可终止。
  3. 终止后：数据按 DPA 处理、款项按已发生服务结清、品牌与技术许可即时停止。

第十条 效力（分阶段约束力）与争议

  1. 分阶段约束力：试点期仅第六、七、八条具约束力；《采购确认单》（附件 A）经双方签署后，正式期条款全面具约束力。
  2. 适用法律与争议：本协议适用新加坡法律并结合属地法；争议提交 SIAC 或双方约定的属地有管辖权机构，仲裁语言 [中文 / 英文]。本条独立生效，不因协议终止而失效。
