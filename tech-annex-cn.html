Technical Specification Annex · Phase 1

《项目专项协议(PSA)》附件一 · 适用于非洲及东南亚试点 · 版本 0.1(草案骨架)

草案骨架 — 内部与谈判用。 本附件列明平台就本项目应满足的功能与技术要求,为 PSA 附件一。重要:本附件仅规定"平台应具备什么能力",不设知识产权、源代码或数据归属条款 —— 这些由 PSA 统一约定:平台为甲方既有 IP、以非转让许可提供(PSA 第5条);业务连续性以数据/内容可携实现,不做核心源码托管(PSA 第10条);数据归属见 DPA。功能标注 MVP 第一阶段 / 后续 迭代 / 待PoC 以试测结论为准。方括号 [ ] 为待填项。
A. 架构与功能模块 B. 角色 · 档案 · 内容 C. AI 能力 D. 教学交付 E. 非功能要求 F. 数据分析与学习闭环 G. AI 治理与安全 H. 数据保护与网络安全 I. 服务水平与灾备 J. 集成 · 扩展 · 成本 K. 验收与分阶段 X. 不在本附件处理的事项

A核心架构与功能模块

平台采模块化、可扩展、API 优先、云端架构;模块可独立增/换/升级而不重构全系统。第一阶段交付以下模块的 MVP 能力,其余按 PSA 变更管理迭代:

模块阶段
用户与身份、学校/机构、班级/学习者、课程体系管理MVP
数字学习内容管理(LCMS)、作业与测评、考勤与课堂参与MVP
AI 批改、AI 虚拟学习伙伴、AI 教师助手、个性化学习引擎、ILAP 引擎MVP
学习数据分析、进度报告、参与度与预警、在线/离线学习MVP
在线直播教学管理、课程录像与媒体管理待PoC
通知与沟通、系统后台、数据与报表、权限与审计、API 与第三方集成MVP
AI 多智能体管理与治理系统MVP

  • 角色与权限:学习者 / 教师 / 学校管理员 / 国家(地区)项目管理员 / 全球项目管理员 / 超级管理员;支持"全球→国家→机构→学校→班级→学习者"多层级。MVP
  • 学习者数字档案:持续更新的学习画像(基本资料、能力维度、出勤/作业/测评、AI 记录、参与度、优势/薄弱、目标与 ILAP、HSK 进度),随学习数据动态更新。MVP
  • 课程内容管理:课程/单元/课次/教学目标/生词/汉字/语法/听说读写/测验/作业/模拟考;可关联 HSK 等级与能力指标;架构支持 HSK 体系更新而不重构。MVP

D教学交付(直播与录像)

  • 在线直播:与经批准的第三方会议平台(Zoom / Google Meet / [Voox 等])集成;建课/排期/生成链接/通知/考勤/在线时长/与班级关联;第三方 API 限制时提供半自动考勤。待PoC(跨境弱网 RTC 与属地链路)
  • 课程录像:按 国家→学校→班级→课程→日期→教师 分类检索;续播/低清下载/离线观看;后续自动字幕/转录/章节/内容搜索。

E非功能要求(核心)

项要求
离线优先 / 弱网核心功能:在线全功能 / 低带宽自动降级(视频/音频/图片/同步) / 离线下载学习 + 网络恢复自动同步不丢数据。MVP
断电适应(非洲版)间歇供电环境:自动保存进度/未完成任务、断电恢复、避免数据丢失、减少重复下载。MVP(非洲)
低配设备 / 移动优先优先入门安卓手机/平板、低配电脑、旧浏览器、有限 RAM/存储;移动优先(PWA / Android App / 二者结合);不得要求高端设备完成核心学习。MVP
流量优化自适应视频/音频压缩/低清下载/数据节省/后台与选择性同步下载。MVP
多国多层级 / 多语言 / 通知多国/校/班/时区并管,新增国家不重构;首阶段英文+简体中文,架构支持扩展;通知支持 App/推送/Email/SMS/[WhatsApp 等]。MVP / WhatsApp 后续

F数据分析与学习闭环

  • 四层分析:学习者 / 教师 / 学校 / 国家(全球);报告导出 Excel / CSV / PDF。MVP
  • 学习闭环:教 → 练 → 测 → 诊断 → 个性化 → 干预 → 再测 → 更新 ILAP → 报告;从"看了多少"走向"学会了什么、下一步学什么"。
  • 预警:识别连续缺课/作业未完成/学习下降/进度落后,向教师或管理员推送。MVP
  • HSK 进度与准备度追踪;平台内"准备度/预测"不得表述为官方 HSK 认证或官方成绩。

GAI 治理与学习者安全

  • 人工监督:AI 分析/建议/辅助,授权教师/管理员保留最终教学判断;可修改/覆盖/纠正/举报/标记 AI 输出;重要 AI 判断不在无人工复核下永久锁定。
  • 儿童安全:服务未成年人时设 AI 安全护栏,不主动提供不适宜/操纵性/不当情感依赖内容;AI 学习伙伴明确定位为学习工具,非人际关系替代。

H数据保护与网络安全

按 PSA 附件五(DPA)与属地法(非洲:尼日利亚 NDPA;东南亚:越 PDPD / 印尼 UU PDP / 马 PDPA / 新 PDPA)执行。至少:身份认证、权限与最小权限、传输与存储加密、管理员多重认证、操作日志与审计、数据保留与删除、同意机制;安全开发/漏洞管理/补丁/监控/入侵防护/备份/灾备/事件响应;重大泄露按 DPA 时限通知。MVP

I服务水平与灾备

月度可用率目标 [99.5%](不含计划维护);严重/普通故障响应、修复时限、RTO/RPO 见 PSA 附件三。平台故障与"当地互联网/电力中断"分列,不混为同一 SLA 责任(见 PSA 第7条)。自动备份/数据库/内容/配置备份 + 定期恢复测试。

J集成 · 扩展 · 成本 · 搜索

  • API 集成:标准化安全 API,支持会议平台/WhatsApp/SMS/支付/身份/移动 App/其他教育与分析平台。
  • 扩展性:架构支持逐步扩展至 [1,000 / 10,000 / 100,000] 学习者;各规模所需服务器/DB/AI/带宽/存储及成本"以实测与届时报价为准",不因规模增长而重构。待实测
  • AI 成本控制:模型路由、小模型处理简单任务、Token 优化、缓存、调用量统计;月度 AI 用量与成本报告。MVP
  • 搜索:全局搜索并遵守权限控制。后续

K验收与分阶段

  • 分阶段:第一阶段仅交付上表 MVP 范围至可用;待PoC 项以试测结论定去留与时点;其余为 后续。
  • 验收(与 PSA 第6条 + 附件四对齐):双方于启动阶段共定验收标准与 UAT 用例,切合属地弱网/(断电)/低配实况。测试至少含:功能、API、集成、网络安全、性能、低带宽、离线、断网恢复、(断电恢复)、低配安卓、AI、AI 错误率/异常输出、UAT。
  • 技术文档:系统架构、DB 结构、API 文档、管理员/教师/学习者手册、AI 架构与智能体说明、安全/备份/灾备/部署说明。
