第一条 合作目的与性质

  1. 合作目的。三方本着优势互补、资源共享、合作共赢、长期发展的原则，共同推动平台的推广与应用，重点包括：（1）海外学校及机构中文教学试点；（2）海外市场推广；（3）与海外政府及教育部门合作；（4）中文教育数字化及 AI 应用；（5）海外师生及机构用户拓展；（6）在适当情况下开展平台商业化运营。
  2. 框架性质。本协议为非排他性战略框架协议。任何具体项目的约束性商业条款，仅在《项目专项协议》（第四条）中产生。
  3. 独立各方。三方以独立合作方身份开展合作，各自对其行为与义务负责，除书面明确授权外无权约束其他方。（标准独立性表述；待协会法律形态确定后可进一步细化。）

第二条 三方定位与职责

2.1 甲方（JE AI）— 技术与平台

  1. 平台研发与技术建设；维护、升级与技术支持。
  2. 面向海外需求的产品优化与功能迭代；按项目提供技术培训与售后。
  3. 自行承担平台前期研发与技术成本（该等投入不因本协议转化为乙方或丙方的任何所有权，见第五条）。
  4. 在合规与本协议范围内，提供合作所需的平台、AI 服务与技术授权。

2.2 乙方（Ray）— 海外市场与资源

  1. 海外市场开发与拓展，重点为非洲及其拓展的其他市场。
  2. 对接海外学校、机构、政府部门及潜在伙伴；协助海外项目的洽谈、签约与落地。
  3. 在其合法能力与资源范围内，协助链接亚洲相关政府及公共资源。
  4. 向甲方反馈市场需求；协助解决项目推进中的问题。凡与公职人员的对接，均受第九条（反贿赂）约束。

2.3 丙方（协会）— 教育资源、标准与品牌

  1. 提供中文教学环境与教育资源；协调并推荐合适的试点学校。
  2. 推动印尼、越南等地区试点；对接学校、教师、学生及机构。
  3. 制定并守护教育与儿童保护标准；支持教学实践、课程应用与教学反馈。
  4. 按第五条条件为合作许可山海同文品牌，并在符合其非营利宗旨的前提下给予背书。
  5. 协会定位为教育资源、标准与品牌及背书方，其角色以此为主，不承担商业交付、销售与收款等主责（该等责任由甲方、乙方及/或当地项目主体承担，见第三条）。

第三条 协会角色与未来非营利地位

当前状态。协会已完成 ACRA 法人登记（独立法人、有限责任）；[慈善 / IPC 地位待申请]。现以法人合作方身份签约，可按专项协议参与项目收益或分配。3.3–3.4 的非营利利润分配限制为前瞻性条款，自其取得慈善 / IPC 地位之日起适用。
  1. 协会以教育资源、标准、品牌及背书方身份参与，可按专项协议约定，取得项目收益分成、成本补偿、资助/赞助或约定的服务费，并存入以协会名义开立的账户、按其会计规则记账。
  2. 签署资格。协会已完成 ACRA 法人登记，由其授权代表按协会章程签署本协议。
  3. 协会取得慈善 / IPC 地位后，将采用非营利环隔（盈余不向成员分配、基金会计），具体见《合规建议书》；三方将据此相应调整商业与财务安排以保护其身份。

第四条 项目专项协议

  1. 就特定国家、地区、学校、政府或机构项目，相关方可另行签署《项目专项协议》（"专项协议"），明确：项目名称；国家/地区；合作对象；各方具体职责；项目成本；收入及收益分配（丙方受第三条约束）；项目负责人；结算方式；项目期限。
  2. 专项协议与本协议不一致的，就该项目商业条款以专项协议为准；但本协议第三条（协会角色）、第五条（知识产权/品牌）、第八条（数据/儿童保护）、第九条（反贿赂）始终优先。
  3. 重大事项——重大商业合作、重大支出、知识产权授权、收益分配、区域独家——须经相关方授权代表书面确认。

第五条 知识产权与品牌

  1. 平台知识产权（甲方）。本协议签署前已存在或甲方独立开发的、与 AI 中文学习平台相关的知识产权与技术成果（代码、算法、JE 引擎、智能体架构、TIDAR-KAG、界面设计、系统架构、技术方案、程序、数据库结构及 AI 模型等），均归甲方所有。本协议不构成向乙方或丙方的转让或共有。
  2. 许可。甲方授予其他方在合作范围内使用及推广平台的非排他、不可转让、可撤销许可。未经甲方书面同意，任何方不得复制、修改、反向工程、出售、再许可或以其他方式处分平台或甲方知识产权。
  3. 品牌（丙方）。山海同文（SHANHAI TONGWEN）主品牌及标识由协会所有。协会就合作授予非排他、可撤销、受质量控制的品牌使用许可，须遵守协会品牌与教育标准；如滥用或损害声誉，协会有权中止许可。使用任何一方名称、商标或标识须事先取得该方同意。
  4. 共同创作内容。因合作共同创作的课程、教材、内容或功能的知识产权，由三方按实际贡献另行书面约定。

第六条 收入、成本与资金分账

  1. 不同国家与项目的商业模式与成本结构存在差异；具体收入与收益分配在各专项协议中约定（丙方受第三条约束）。
  2. 收益分配前，应先明确项目收入、平台/技术成本、当地运营成本、市场推广成本、教师/教学成本、税费及其他必要支出。
  3. 资金分账。各方使用自有账户，不得混同。学生费用与商业收入由甲方及/或指定当地项目主体收取，或按专项协议另行约定。应付协会的款项（收益分成、补偿、资助或费用）存入以协会名义开立的账户并按其会计规则记账。
  4. 未经相关方书面确认，任何方不得单方面改变项目收费标准、分配比例或结算方式。
  5. 甲方前期投入不转化为乙方或丙方的任何所有权；如需垫付，须事先确认并在专项协议中约定。

第七条 资源登记与反绕开

  1. 三方建立项目登记与客户报备机制，记录各方开发的项目（乙方海外项目；协会引荐的学校/机构；甲方直接客户）。
  2. 未经引荐方书面同意，任何方不得绕过该方，直接就同类合作与其引荐的政府、学校、机构或客户建立合作。
  3. 违约造成实际损失的，应承担相应责任；具体保护期限与救济可在专项协议中约定。

第八条 数据保护与儿童保护

  1. 三方遵守新加坡《个人数据保护法》（PDPA）及各项目所在国适用的数据保护、隐私与网络安全法律。
  2. 角色。每个项目以《数据处理附录》（附件三）明确学生、教师、学校及用户数据的控制者与处理者角色、目的与留存、安全措施及跨境传输保障。
  3. 未成年人。学生通常为未成年人。三方应取得可验证的家长/监护人同意，遵循数据最小化，且不得将未成年人数据用于项目目的之外。
  4. 儿童保护。三方采纳并遵守《儿童保护政策》（附件四），包括与儿童接触人员的背景审查、行为规范与事件报告。
  5. 任何方不得将合作所取得的数据用于与项目无关的用途。

第九条 反贿赂、制裁与合规

高风险领域。合作涉及与外国公职人员对接及跨境 AI 服务。本条保护全体三方，尤其保护协会。
  1. 各方遵守新加坡《防止贪污法》《贪污、贩毒及其他严重罪行（没收利益）法》及各相关法域适用的反贿赂反腐败法律。
  2. 任何方（及为其行事者）不得为获取或保留业务或任何不正当利益，向任何人（含政府官员）提供、给予、索取或收受贿赂、回扣或不正当好处；禁止"疏通费"。
  3. 各方遵守与平台及 AI 服务相关的制裁与出口管制法律，不在受禁背景下部署。
  4. 各方保存准确记录，并就任何可信的违反指控及时通知其他方。违反本条构成重大违约，可立即中止或解除。

第十条 保密

  1. 各方对合作中获得的商业秘密、技术资料、客户/学校资料、政府资源信息及价格/收益信息承担保密义务，未经提供方书面同意不得向无关第三方披露。
  2. 保密义务于协议终止后继续有效，期限依信息性质确定（默认 [ 三 ] 年，商业秘密与个人数据为无限期）。

第十一条 责任、赔偿与保险

  1. 各自领域负责。各方就其自身违约、过失或违反第八、九条的行为，向其他方赔偿由此产生的损失。
  2. 责任上限。除违反第五、八、九、十条、欺诈或法律规定不得限制的人身伤亡外，各方对其他方的累计责任以 [ 该方在相关专项协议下前 12 个月应付/应收金额 / 固定金额 ] 为上限。
  3. 丙方。协会的累计责任以其自身故意或重大过失造成的直接损失为限；不对项目的商业或间接损失负责。
  4. 任何方不对间接或后果性损失负责。各方在合理可得的范围内为其活动投保。

第十二条 期限、解除与退出

  1. 期限。自最后一方签署之日起 [ 三 ] 年，经协商可续签。
  2. 三方可协商终止。一方严重违约且经书面通知后 [ 30 ] 日内未改正的，其他方有权终止与该方的合作。
  3. 一方退出不影响已签署并在履行的专项协议，相关项目按其条款继续或另行处理。甲方退出后，其平台知识产权仍归其所有。
  4. 存续与善后。第五、八、九、十、十一条及已发生的结算义务继续有效。终止后，各方返还或删除其他方的保密与个人数据（法定留存除外），品牌与知识产权许可终止。

第十三条 不可抗力

因战争、疫情、自然灾害、政府政策或法律变化等超出一方合理控制的原因导致无法履行的，该方不承担责任；三方应善意协商调整受影响项目。

第十四条 适用法律与争议解决

  1. 本协议的签署、履行及解释适用新加坡法律。
  2. 三方应先友好协商；协商不成且逾 [ 30 ] 日的，提交新加坡国际仲裁中心（SIAC）按其规则仲裁，仲裁地新加坡，仲裁员 [ 一 ] 名，语言英文。

第十五条 其他

  1. 本协议（含附件与专项协议）为其标的之完整约定，取代此前谅解。
  2. 修订须经三方书面签署；权利不因未行使而放弃；某条款无效不影响其余条款效力。
  3. 通知以书面形式送达签署栏所载地址/邮箱。
  4. 语言。本协议以中英文签署。英文版（English version）与本中文版并行；如有冲突，以 英文版为准 [或按三方偏好约定以中文版为准 — 待确认]。
  5. 本协议可分份签署（含电子签署），各份具同等效力。
